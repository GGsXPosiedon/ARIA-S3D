- `assets/aria_textured_mesh.glb` — primary textured model with embedded PNG
- `assets/aria_textured_mesh.obj` — secondary textured model
- `assets/aria_textured_mesh.mtl` — OBJ material sidecar
- `assets/aria_albedo_texture.png` — 2048 x 2048 photographic atlas
- `assets/xatlas_*` — UV atlas and mapping artifacts
- `assets/*validation*.txt` — final validation reports
- `assets/*stats*.txt` — projection and atlas statistics
